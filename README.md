# Lista de Exercícios Python

Este repositório contém uma coleção de exercícios rápidos para prática da linguagem Python.

## Objetivo

- Fornecer pequenos desafios que ajudam a fixar a sintaxe e os conceitos básicos de Python.
- Permitir prática rápida e iterativa com scripts simples.
- Ajudar no desenvolvimento de habilidades de programação por meio de exemplos práticos.

## Como usar

1. Abra o arquivo desejado em um editor de código.
2. Execute o script em Python.
3. Modifique e experimente novas variações para aprender mais.

## Destaques

- Cada arquivo é um exercício ou exemplo autônomo.
- Ideal para iniciantes e para revisões rápidas.
- Não há dependências externas necessárias, apenas o Python instalado.
- O projeto está em andamento e sendo atualizado frequentemente.

## Requisitos

- Python 3.x
